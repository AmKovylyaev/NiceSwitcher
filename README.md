# NiceSwitcher

Локальный автопереключатель русской и английской раскладки для macOS с постепенным персональным обучением.

Проект находится на стадии требований. Приложение пока не реализовано.

## Документация

- [Требования к проекту](docs/mac-layout-switcher-requirements.md) — исходный документ от 10 ноября 2026 года.

Согласно ТЗ, первый этап разработки — проверка возможности добавлять исправления в стандартную историю Undo/Redo целевых редакторов macOS.
