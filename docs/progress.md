## Правила приёмки

Основной агент проверяет соответствие ТЗ и качество кода лично, по указанию пользователя. Исполнители не создают дополнительных агентов. Открытые ошибки возвращаются исходному исполнителю. Непроведённые живые macOS-тесты не считаются успешными.
