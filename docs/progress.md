# NiceSwitcher: журнал реализации

10 ноября 2026 пользователь одобрил маршрут из `docs/reviews/2026-11-10-implementation-review.md`, Swift, компактный baseline, MIT и исполнителей Luna max с проверкой основным агентом. Пользователь проведёт живые испытания на своём Mac.

## Состояние

- Репозиторий публичный по явному указанию пользователя.
- M0: план подготовлен; стенд ещё не реализован; живые испытания ожидаются.
- M1–M5: milestones созданы; реализации пока нет.
- M6: backlog после стабильного RU/EN.
- Среда: Linux, Swift toolchain устанавливается из официальной поставки. macOS/Xcode недоступны.

## Правила приёмки

Основной агент проверяет соответствие ТЗ и качество кода лично, по указанию пользователя. Исполнители не создают дополнительных агентов. Открытые ошибки возвращаются исходному исполнителю. Непроведённые живые macOS-тесты не считаются успешными.
